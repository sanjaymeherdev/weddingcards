Invitation Admin

Update photos and music with public links

1 · Photos

Paste a public image link (https://…). A preview appears instantly. Google Drive and Dropbox share links are converted automatically.

2 · Music

Paste a direct link to an MP3/M4A/OGG file. Leave empty to use the built-in soft instrumental.

3 · Save

Preview first, then save. Saving commits config.json to GitHub, and the live site updates after your host redeploys (usually under a minute).

GitHub connection
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: only weddingcards. Permission: Contents → Read and write.
  3. Paste it above. It is kept only in this browser. Without it nobody can save changes.
